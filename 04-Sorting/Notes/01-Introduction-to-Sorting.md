# Introduction to Sorting

## What is Sorting?

Sorting is the process of arranging data in a specific order.

The most common orders are:

- Ascending Order
- Descending Order

---

## Example

### Unsorted Array

```text
[7, 2, 9, 1, 5]
```

### Ascending Order

```text
[1, 2, 5, 7, 9]
```

### Descending Order

```text
[9, 7, 5, 2, 1]
```

---

# Why Do We Need Sorting?

Sorting makes data easier to process and search.

Many algorithms become significantly faster once the data is sorted.

Examples include:

- Binary Search
- Merge Intervals
- Two Pointers
- Duplicate Detection
- Median Finding
- Scheduling Problems

---

# Types of Sorting Algorithms

Sorting algorithms are generally divided into two categories.

## Comparison-Based Sorting

These algorithms compare two elements to determine their order.

Examples:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

---

## Non-Comparison Sorting

These algorithms do not compare elements directly.

Examples:

- Counting Sort
- Radix Sort
- Bucket Sort

These algorithms work only under specific constraints.

---

# Characteristics of a Sorting Algorithm

Every sorting algorithm is evaluated based on several properties.

## Time Complexity

How long does it take to sort?

Examples:

- O(n²)
- O(n log n)

---

## Space Complexity

How much extra memory is required?

Examples:

- O(1)
- O(n)

---

## Stable Sorting

A sorting algorithm is stable if equal elements maintain their original relative order after sorting.

---

## In-Place Sorting

An in-place sorting algorithm sorts the array without using significant extra memory.

Typically:

```text
Space Complexity = O(1)
```
