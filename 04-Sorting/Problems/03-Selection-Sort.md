# Selection Sort

## Problem Statement

Given an unsorted array of integers, sort the array in ascending order using the Selection Sort algorithm.

---

## Example

### Input

```text
[5, 3, 8, 4, 2]
```

### Output

```text
[2, 3, 4, 5, 8]
```

---

## Constraints

- Sort the array using Selection Sort.
- Perform the sorting in-place.

---

# Expected Approach

For every position,

1. Find the smallest element from the remaining unsorted portion.
2. Swap it with the current position.

---

## Time Complexity

Best

```text
O(n²)
```

Average

```text
O(n²)
```

Worst

```text
O(n²)
```

---

## Space Complexity

```text
O(1)
```
