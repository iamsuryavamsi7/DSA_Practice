# Bubble Sort

## Problem Statement

Given an unsorted array of integers, sort the array in ascending order using the Bubble Sort algorithm.

---

## Example

### Input

```text
[5, 3, 8, 4, 2]
```

### Output

```text
[2, 3, 4, 5, 8]
```

---

## Constraints

- The sorting must be performed using the Bubble Sort algorithm.
- Sort in ascending order.
- The algorithm should modify the array in-place.

---

# Expected Approaches

## Basic Bubble Sort

Repeatedly compare adjacent elements and swap them if they are in the wrong order.

Time Complexity

```text
O(n²)
```

Space Complexity

```text
O(1)
```

---

## Optimized Bubble Sort

Stop early if no swaps occur during a complete pass.

Best Case

```text
O(n)
```

Average Case

```text
O(n²)
```

Worst Case

```text
O(n²)
```

Space Complexity

```text
O(1)
```
