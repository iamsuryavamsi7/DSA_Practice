# Merge Sort

## Problem Statement

Given an unsorted array of integers,

sort the array in ascending order using the Merge Sort algorithm.

---

## Example

### Input

```text
[7, 3, 8, 2, 6, 4, 5]
```

### Output

```text
[2, 3, 4, 5, 6, 7, 8]
```

---

## Constraints

- Sort using Merge Sort.
- Use recursion.
- Merge the divided arrays correctly.

---

# Expected Approach

1. Divide the array into two halves.
2. Recursively sort both halves.
3. Merge the sorted halves.

---

## Time Complexity

Best

```text
O(n log n)
```

Average

```text
O(n log n)
```

Worst

```text
O(n log n)
```

## Space Complexity
