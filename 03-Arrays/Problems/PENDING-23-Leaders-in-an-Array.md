# Leaders in an Array

## Problem

Given an array of integers, print all leader elements.

A leader is greater than every element on its right.

---

## Example

Input

```text
[10,22,12,3,0,6]
```

Output

```text
[22,12,6]
```

---

## Expected Approaches

### Brute Force

Time

```text
O(n²)
```

---

### Optimal

Reverse Traversal

Time

```text
O(n)
```

Space

```text
O(1)
```
