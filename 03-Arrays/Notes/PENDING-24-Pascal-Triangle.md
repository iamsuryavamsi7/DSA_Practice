# Pascal Triangle

## Concepts

- Combinations
- Binomial Coefficients
- Dynamic Programming
- Pattern Generation

---

## Pattern

Every number equals

```text
Top Left

+

Top Right
```

Example

```text
      1
     1 1
    1 2 1
   1 3 3 1
```

---

## Time Complexity

```text
O(n²)
```
